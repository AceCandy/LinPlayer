# 手机流影独立短视频播放器

## 目标

手机流影使用独立的短视频播放链路，改善整页上下滑动、连续切片和首帧等待体验；不再通过通用播放页换皮实现，不改变通用播放器行为。

## 授权与状态

2026-10-22 用户审阅方案后以“ok 改”批准实施，审查修复后明确授权“提交归档 然后打个手机包”。提交与出包不代表真机性能验收完成；AC9仍未验。已确认的产品决定统一收敛在下表，不保留重复的临时讨论清单。

## 需求

| ID | 要求 |
|---|---|
| R1 | 手机独立流影播放页与会话，不嵌入通用 PlayerPage；只使用Media3，不跟随普通内核设置、不回退MPV；保留标准 Emby 取流、权限和播放记账能力。 |
| R2 | 上滑下一条、下滑上一条采用整页跟手与吸附；未确认切换则回弹。加载中的页面仍可继续滑动，只有当前落定目标可正式播放。 |
| R3 | 保留当前来源、普通/卍解、舞蹈/直播、频道/衣着及收藏范围；候选分页有界，提前准备下一页且失败可重试，不重新随机替换选中项。 |
| R4 | 前一条/当前/后三条分层准备：前条复用有效数据，下一条优先准备媒体和画面，更远条目准备播放信息及有限起播数据；当前播放优先，连续滑动提高最新目标优先级。最多两个播放器/解码槽，只允许一路声音与一个正式播放会话。 |
| R5 | 退出保留可校验的磁盘媒体缓存，回滑、循环与再次进入可复用；按身份、版本、预算和过期规则管理。不保存长期播放凭据、解码帧或续播断点，不新建离线播放能力。 |
| R6 | 当前视频卡顿、低内存、备用解码器不足或后台时收缩准备；无法预加载或没有缓存时正常起播，不能阻塞滑动、假成功或偷换视频。Media3 不支持的内容显示错误，不换 MPV。 |
| R7 | 保留既定控件、独立 liuying_speed、静音、收藏面板及短按/长按语义；暂停、音频焦点和生命周期状态分离，面板和进度输入不穿透切片。 |
| R8 | 自动连播使用同一切换流程；循环仅在当前有效会话内对可定位媒体从0重播，不重建实例或重新取流，不适用退出重进的重新授权流程；不可定位时明确提示。每次选择视频从头开始，不建立本地流影观看断点。 |
| R9 | 切后台/锁屏立即暂停、停止投机加载；返回前台只恢复此前正在播放的有效目标，手动暂停仍暂停。离页取消请求并收尾正式会话，旧请求和旧清理不能操作新会话。 |
| R10 | 不修改通用播放器 UI、内核选择、默认参数、预加载单槽、缓存配置或后台播放策略；必要的底层接管/缓存能力只作显式隔离的兼容扩展。TV、桌面及其它任务保持原行为。 |
| R11 | 同设备/网络/媒体集建立原始基线，分别衡量冷起播、热切片、连续下滑、回滑及跨页；记录真实首帧、网络请求、内存、磁盘和失败，不以 READY 或动画代替视频呈现证据。 |

## 验收标准

| ID | 对应需求 | 可观察的通过条件 |
|---|---|---|
| AC1 | R1/R2/R7 | 手机流影不实例化通用播放页；整页拖动、快速滑动、回弹和吸附可操作，单击暂停、横滑进度、按钮与面板互斥。 |
| AC2 | R2/R4/R6/R9 | 挂起旧请求或停止上报后连续切换，再放行；手势及返回不被锁住，仅保留一个在途提交和最新待提交目标，不积压中间播放；新目标不被覆盖，只有一个正式播放会话和一路声音。 |
| AC3 | R3 | 分类、标签、收藏、卍解、账号/空间变更拒绝旧数据；页边界、分页错误、空页回退和收藏点选保持正确范围、seed及索引。 |
| AC4 | R4/R6 | 对可预载点播分别观察N+1深准备、N+2轻准备、N+3信息/有限起播数据；核心待准备项含在途最多3条，滚动或回滑让最远未选项让位，候选元数据不算媒体准备证据。资源不足可缩减深度；真正实时源零内容预热/备用首帧；卡顿或压力撤回投机任务而不停止当前播放。 |
| AC5 | R5 | 关闭重进及进程重启可复用有效已下载块；授权失败、媒体版本变化、损坏/残块、缓存清理及容量淘汰不使用无效字节。挂起清理前probe并在清理返回后放行，旧请求不能新建缓存或回填，新代请求仍可缓存。缓存不无限增长，不改变普通缓存配置。 |
| AC6 | R6/R7/R8 | 两种普通内核设置下流影仍只创建Media3；不支持内容明确失败且零MPV回退；倍率双向隔离；循环不重新解析/重建；自动连播范围正确。 |
| AC7 | R7/R9 | 系统前后台、锁屏、手动暂停与音频焦点交错测试通过；返回只按有效意图恢复；离页后零活动流影播放器/投机任务，磁盘缓存按策略保留。 |
| AC8 | R10 | 通用播放器和TV相关回归、核心/绑定/参数门禁通过，普通调用省略专用参数时行为不变；其它任务文件零改动。 |
| AC9 | R11 | 真机同条件前后报告包含冷/热切片P50/P95、连滑及回滑、卡顿/失败、请求/字节、内存峰值与磁盘预算；无设备则明确该验收未完成，不声称抖音级秒切。 |

## 范围外

- 不改普通播放 UI/OSD/设置、TV/桌面布局、服务端行为或其它活跃任务。
- 不做自研解码、MPV回退、评论/关注/分享、全页下载、离线播放、跨服收藏。
- 不承诺任意格式、任意网络均无缝切片；数字性能目标在设计中标为待基线校准。
- 不自动提交、归档、推送或构建安装包；正式设计只同步实际实现及其验证边界。

## 实施状态

独立播放链路、候选窗口及缓存接管已实施，当前按implement.md检查清单与validation.md记录验证。AC9缺少真实手机、实服及旧版性能基线，保持未完成；不能将单测或编译作为秒切性能证据。
