# TV 非播放 UI 审查线索

范围：当前工作树的 Android TV Compose 页面与 `tv/kit`。静态阅读；未运行、未构建、未读 `UI_TV.md` 等大型设计正本。焦点跳转、裁切、实际观看距离和操作反馈时序均需设备或截图验收；以下不把它们写成已证实的运行时故障。

## 高价值改进候选

### 1. 下载首次读取失败会一直显示骨架

- 优先级：P1，反馈完整性。
- 事实：`tv/ListPages.kt:291-305` 每两秒 `runCatching { app.call("download.list") }.getOrNull()?.let { ... tasks = list }`；失败分支不更新状态，也不调用 `app.report`。页面在 `tv/ListPages.kt:331-334` 用 `list == null` 表示骨架。
- 推断：首次请求持续失败时用户只看到加载占位，无法区分慢加载、断网或空队列；后续轮询失败则保留旧列表，没有“数据可能过期”的提示。
- 建议：明确区分首次失败与轮询失败；前者提供可重试错误态，后者保留数据并给轻量状态提示。
- 验收：让首次 `download.list` 失败时出现可操作的错误反馈；成功后断开请求时仍保留已有任务；空队列仍走现有空态。

### 2. 服务器连通状态只用颜色点表达

- 优先级：P2，三米外可读性 / 状态辨识。
- 事实：`tv/ServersPages.kt:145-151` 加载真实探测结果；`tv/ServersPages.kt:277-285` 卡片只在名称旁显示 `StatusDot`（成功绿、失败红、未探测灰），活动源另显示文字“当前使用”。服务器卡尺寸为 `256.dp × 150.dp`（`tv/ServersPages.kt:289-293`）。
- 推断：非活动源的“不可达 / 尚未探测”依赖颜色区分；距离远、色觉差异或低对比屏幕下含义较难确认。
- 建议：为探测结果补短文字状态（如“可连接 / 不可达 / 未测速”），保留颜色作为辅助。
- 验收：不看颜色也能区分三种探测状态；活动源标记仍明显；长服务器名与备注布局不挤压状态文字（需 TV 画面验证）。

### 3. 卡片的长按菜单缺少统一的可见提示

- 优先级：P2，遥控器可发现性。
- 事实：公共卡片支持 `onLongClick` 并映射 Menu 键（`tv/kit/TvKit.kt:117-127, 288-323`）；媒体库卡片的屏蔽动作由长按打开（`tv/LibraryPages.kt:103-125`），收藏卡片菜单由 `menu` 回调打开（`tv/ListPages.kt:149-152`），而服务器页标题明确写了“按确认键打开操作”（`tv/ServersPages.kt:196`）。
- 推断：常用卡片的次要动作依赖用户知道长按或 Menu 键；服务器页已有可见说明，其它使用同一交互的卡片页未见同类提示。
- 建议：在媒体卡片共用的页面级帮助中说明“长按 / Menu：更多操作”，避免每张卡增加焦点项。
- 验收：首次进入库、收藏、详情相关推荐时能找到操作提示；长按与 Menu 键仍打开同一菜单，短按仍进入详情。

### 4. 搜索结果的海报预览偏小，搜索区为固定双栏

- 优先级：P2，远距层级 / 信息扫描。
- 事实：搜索页面左侧固定 `300.dp` 输入与历史栏，右侧承载范围筛选和结果（`tv/SearchPage.kt:144-179`）；普通结果行海报为 `38.dp × 57.dp`，标题与年份/类型各一行（`tv/SearchPage.kt:294-305`）；结果上限 60 条，分集结果另以横向宽卡呈现（`tv/SearchPage.kt:290-319`）。
- 推断：普通结果主要靠文字识别，封面在 960dp 设计画布上占宽很少；两栏也压缩了结果区，长标题及 60 条连续列表的扫读效率值得实机检查。
- 建议：评估放大普通结果海报或改成更易扫读的结果卡，并保留历史和范围切换的可达性。
- 验收：在 960×540dp 类型 B 画布上比较封面识别、标题截断和结果区可见行数；确认上下翻结果、左右切入历史/范围筛选无焦点迷失（静态无法确认）。

### 5. 媒体库内缺少“在当前库搜索”的直接入口

- 优先级：P2，导航连续性（需产品确认是否纳入路线图）。
- 事实：库网格只提供“筛选与排序”入口（`tv/LibraryPages.kt:234-241`）；全局搜索只提供“当前服务器 / 聚合全部”及“包括分集”条件（`tv/SearchPage.kt:173-178`），普通查询调用 `emby.search` 时传 `query/types/limit`，未传库 ID（`tv/SearchPage.kt:104-114`）。
- 推断：用户在单库浏览时无法直接把搜索范围缩到当前库；需切到全局搜索，搜索结果可能覆盖同服务器其它库。
- 建议：若产品支持库内搜索，在库页提供入口并把 `viewId` 作为搜索范围传递；否则明确全局搜索的范围说明。
- 验收：从某库发起搜索只返回该库匹配项；返回库页后排序、筛选及滚动位置保持。

### 6. 长季剧集的季切换与播放目标需要端到端可读性验收

- 优先级：P2，关键流程验收（不是已发现的逻辑缺陷）。
- 事实：详情页会按续播集/首个未看集确定默认播放目标，按钮直接写出目标集（`tv/DetailPages.kt:474-493,505-570`）；切季只替换分集行，季名以 `ScopeChips` 横排（`tv/DetailPages.kt:572-590`）；分集项横向浏览，目标集不在首屏时会先滚到目标项（`tv/DetailPages.kt:640-690`）；集详情可切紧凑/详细列表，紧凑模式以 `52.dp × 36.dp` 的 `E${episodeNo}` chip 显示集号（`tv/EpisodePage.kt:189-205,234-277`）。
- 推断：季名较长、多季、百集以上及目标集落在后段时，季切换和“主播放目标 / 当前浏览集”关系需要真实遥控器验证；尤其紧凑 chip 只显示集号、不显示季号。
- 建议：针对长剧和跨季续播做专项走查；若看错集风险成立，再调整季标识或目标提示，不改动当前已实现的目标选择逻辑。
- 验收：续播目标与浏览季不同、单季超过 100 集、多季长名称、目标集不在首屏；按返回回到剧详情时季选择与焦点位置符合预期。

### 7. 服务器列表请求失败与“尚无服务器”需要区分

- 优先级：P2，错误反馈一致性。
- 事实：`tv/ServersPages.kt:145-151` 对 `account.listAccounts` 失败使用 `getOrNull()`，结果会成为空 `raw`；主区随后无条件显示卡片网格与添加卡（`tv/ServersPages.kt:187-215`），没有对应的加载/错误分支。探测请求单独异步执行。
- 推断：在账号列表请求失败时，用户可能把空网格理解为没有配置服务器；添加入口仍可见，但没有说明数据读取失败。
- 建议：为初次加载、空列表、读取失败分别提供状态；刷新失败时如已有列表则保留旧值。
- 验收：模拟账号列表首次失败、成功空列表、成功有数据和后续刷新失败，四种状态文案/操作不同且已有卡片不会消失。

## 页面与能力覆盖

- 导航与 kit：固定八项“搜索 / 首页 / 媒体库 / 收藏 / 发现 / 下载 / 服务器 / 设置”（`tv/kit/TvKitShell.kt:57-61`）；轨道收起显示图标、获焦展开覆盖内容（`tv/kit/TvKitShell.kt:63-85,117-149`）；页面焦点记忆、下钻栈和返回见 `tv/TvNav.kt:19-65,78-108,116-156`；公用卡片焦点白框、选中琥珀框、聚焦标题跑马灯见 `tv/kit/TvKit.kt:285-343`。
- 首页：Hero 推荐 / 手动换一部、继续观看、接下来看、逐库最新、合集与插件首页栏目；本机源显示无推荐提示（`tv/HomePage.kt:100-105,127-159,167-200,301-374`）。
- 媒体库与搜索：库选择含屏蔽库恢复入口；库网格固定六列，含排序、类型/年份/已看筛选、分页与重试（`tv/LibraryPages.kt:68-134,151-281`）；搜索支持历史、当前服务器/聚合源、包含分集、插件快捷动作、失败重试及集结果横卡（`tv/SearchPage.kt:84-197,264-325`）。
- 收藏 / 历史 / 下载：收藏按集、电影/剧集、数据源分组，可排序、分页；历史支持当前/全部服务器；下载显示活动与完成任务、速度、进度、重试/暂停/播放、删除确认及下载设置（`tv/ListPages.kt:81-230,282-417,466-548`）。
- 发现：排行榜与 Bangumi/Trakt 放送表，分类、星期切换、媒体库命中与未解锁门（`tv/DiscoverPage.kt:70-135,138-258,260-`）。
- 详情 / 集：播放目标、续播/从头、收藏、更多、季切换、分集、相似推荐和演员；集页有版本/音轨/字幕/线路选择、播放状态与紧凑/详细选集（`tv/DetailPages.kt:295-345,414-628,640-713,878-`；`tv/EpisodePage.kt:83-210`）。
- 服务器 / 设置：服务器卡、连接探测、分组数据源、排序模式、线路测速/同步；设置有分类侧栏、分组加载、即时切换与失败回滚（`tv/ServersPages.kt:128-256,392-`；`tv/SettingsPage.kt:81-133,145-160`）。
- 本地与扩展入口：本机文件夹授权、目录选择/浏览、面包屑、视频播放；路由映射还包括添加服务器、插件页、扩展、来源详情（`tv/LocalPages.kt:94-167,185-249`；`tv/TvApp.kt:250-281`）。

未覆盖：播放 UI；插件自绘页面/数据源各页细节；设计正本与草稿逐项对照；模拟器、实机、截图、自动化与运行时焦点路径验证。源码事实不等价于用户实际体验。
