# TV 详情页影院布局与手机风格统一

用户已确认电影/电视剧两张预览并要求先实现一版；沿用此前自主推进授权。

## 范围
- TV 详情的头图、字阶、类型标签、主操作和媒体选择器按预览统一手机视觉语言。
- 电影和电视剧保留沉浸背景；主操作未聚焦使用主题强调色，焦点反色轻放大，无额外外框。
- 可切换项继续独立可达；无候选的项不显示假的下拉入口。视频目前为只读规格，不新增未实现的切轨协议。
- TV 剧集展示真实待播放分集的媒体选项；手机布局及请求/播放契约不变。
- 常规 TV 窗口首屏可看见分集缩略图；大字号/长标题自然增高滚动，不裁切。

## 验收
- [x] 电影首屏主操作、标签和参数可见；选择版本/音轨/字幕、关闭返回焦点有效。
- [x] 剧集仅取真实 nextEp 的媒体参数，切季/目标更新不继承旧版本及字幕，不查询整剧媒体。
- [x] 剧集首屏可见分集缩略图，参数→选季/分集→返回主操作完整回顶。
- [x] 手机选择、缓存、季集、插件/私密回归保留，浅色和大字号可读。
- [x] 独立审查、实际 Compose 渲染及按键证据完成；不把合成图当真机。

不改核心接口、播放器、导航栈、首页或设置；不出包、不推送。实施验收后用户已授权提交并归档本任务。
