# 统一 Go 核心与各端展示职责

## 目标与范围

用户授权尽量收拢到各端原生 UI + 统一 Go 核心。本任务完成跨端展示缓存及相关候选、全季聚合规则迁移；播放器、系统适配、图片解码与焦点/滚动等页面状态保留在宿主。原 tvOS 界面对齐任务独立保留真机验收。

## 已完成验收

- 普通区与私密区统一核心持久缓存，服务器、账号、空间及查询隔离；清理与状态更新阻止旧请求回写。
- Android BrowseCache/DetailCache、桌面 MetaCache 生产实现移除，各端通过核心 partial 展示快照，实时 result 决定操作；网络失败保留资料，失效错误清除旧展示。
- Android 首页候选池迁入核心 emby.cachedItems；桌面完整季分页聚合迁入 seasonEpisodes(all=true)，默认分页保持兼容。
- tvOS 剩余浏览页面接入快照，缓存预览不推进实时分页游标。
- 核心、绑定及宿主针对性回归和独立复核完成，结果见 implement.md。

## 交付边界

源码迁移完成；不生成安装包、不提交或推送。真实设备、真实服务器体验尚未验收，不能据此声称全部跨端业务与 UI 已完全统一。缓存键升级首次浏览重建，旧宿主快照不导入。
