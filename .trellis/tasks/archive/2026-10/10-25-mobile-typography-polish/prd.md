# 手机端字号层级与细节精修

## 目标

在保留影院深色基调、琥珀/蓝紫强调色的前提下，通过字号层级和细节收敛让手机端更精致；用户确认以当前判断为准重排字阶，旧规范冲突处同步改写。

## 要求

1. 字阶：头图片名与详情主标题28/36·700，引导大标题22/30·700，媒体一级栏目新增 `LpText.rail` 20/28·600；中文零字距、显式行高不变。
2. 栏目标题（`MediaRowHeader`、`SectionTitle`）去掉左侧装饰竖条，只靠字号字重与留白分层。
3. 动态数字使用系统字体+`tnum`（内置字体已于 10-13 移除，宋体测宽结论不再适用），须实测宽度稳定。
4. 续播按钮主文案「继续观看」，剩余时长单独一行且只到分钟；作品总时长十分钟以上不带秒。
5. 媒体信息布尔值显示「是/否」；倍速读数单行，放不下时缩小字号，命中区保持48dp。
6. 弹幕图标与字幕图标可区分。
7. 不改动其它会话的榜单/隐私改动，不打包、不推送。

## 验收

- [x] PhoneTypographyTest 时间数字等宽、M3槽位字族与零字距通过。
- [x] Android 全量单元测试 972 项：969 通过、3 跳过；3 项失败均为隐私排行榜断言，属其它会话进行中的改动，与本任务无关。
- [x] 详情、首页、播放器 OSD、媒体信息截图目视确认。
- [x] UI_MOBILE.md、UI_TV.md、android.md、type-safety.md 冲突条目同步。
