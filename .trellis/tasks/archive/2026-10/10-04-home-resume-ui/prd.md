# 手机首页续播卡片信息优化

用户要求继续 UI 优化；未指定页面时先优化手机首页继续观看。

## 范围与验收
- 保留横版尺寸、两行标题、点击详情与长按菜单、请求次数。
- 剧集主标题保留剧名，副标题显示集号与单集名；缺字段不出现空分隔符。
- 续播封面左下展示剩余分钟，仅有效未完成进度显示；其它卡片保持原样。
- 深浅主题与 1.3 倍字号真实渲染；首页请求回归通过。
- 不修改 TV、播放或网络逻辑；不提交。

## 实现边界
沿 HomePage.RowBlock → LpRow → MediaCard 传显式续播标记，默认关闭。仅修改 Cards.kt、HomePage.kt、对应测试和手机 UI 正本。复用现有主题色、尺寸和测试工具。

## 参考
CineIsle EmbyMediaCard.kt 的剩余时间角标；JellyCine MediaItemText.kt 的集号与集名分层。
