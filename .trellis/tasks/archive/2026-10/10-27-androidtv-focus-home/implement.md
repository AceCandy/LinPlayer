# 执行与验证

1. 完整读取将改代码及调用点；补首页回顶与无外框聚焦回归。
   - 验证：新增用例在原实现失败，并留存失败原因。
2. 先修首页顶栏/回顶，再修共享与专用控件焦点视觉。
   - 验证：显示/隐藏库、续播有/无的方向键往返；不改变详情返回记忆。
3. 批量检查深浅主题渲染和代表页面（首页、列表、详情、设置、弹窗）。
   - 验证：焦点清楚、业务选中仍存在、无双框与遮挡。
4. 独立复核整个 diff，补必要回归并同步规范。
   - 验证：针对性 JVM 测试、`check-android-args.py`、`git diff --check`。

## 环境

- 固定项目 JDK 21、Android SDK 和 `.toolchain/gradle` 缓存。
- 只执行相关 `:app:testDebugUnitTest`，不执行 assemble/pack。
- 截图保留于已忽略的 build 目录，不入仓合成图片或调试日志。
- 真实电视、实体遥控器、真实片源未验则明确标注，不以 JVM 回归代替。
