# 技术设计

## 决策与边界

正式工程置于 `apps/tvos/`：SwiftUI 页面和导航，UIKit 视频/字幕表面，Go C ABI 业务接入。产品范围以最新 PRD 和 [逐页矩阵](research/product-alignment.md) 为准，现行 Android TV 的共享页面是基准；早期最小闭环只作为已建立的技术底座，不再作为功能裁剪理由。固定 AetherEngine 7.39.0 默认组件；运行目标下限为 tvOS 18，当前设备为 tvOS 27，下限兼容性不作已验声明。

当前已有生成 Swift 绑定与唯一事件泵；继续复用，不另造传输层。延续弱类型参数/JSON 结果，页面 DTO 按真实 handler、总线转换和最终信封验证；空会话允许 null/空对象，非空损坏会话继续失败。C 函数声明直接接入 Go 生成头文件，不手抄 ABI。

## 产品对齐实现边界（本次新增）

### 页面与组件

- 新增统一顶部导航，名称/入口和当前 Android TV 一致。SwiftUI 路由显式区分首页、收藏、聚合、搜索、设置与下钻页；不能再只把所有导航目标建模为 MediaItem。各栏目保留自己的返回路径、加载列表和焦点，不靠切页重建整个 AppModel。
- 首页保留横幅、媒体库、继续观看、各库最新、合集及已支持插件栏目；复用一组海报/横卡、区块标题、加载/重试/空态、筛选和操作菜单。视觉以当前共享组件和实际 Android TV 为准，不能从旧独立 TV 页照抄布局。
- 详情补齐版本/线路/字幕预选、已看/收藏、季集与相似内容；搜索、收藏、聚合、榜单/日历、服务器/线路、设置各有实际页面与请求，不提供未接业务的占位入口。
- 只在多个页面需要时抽共用 SwiftUI 控件或 DTO；页面局部状态留在页面/路由拥有者，不建立通用页面生成框架。主题、尺寸和字阶集中为 tvOS token，继承现行产品视觉，再适配实际电视安全区/焦点。

### 会话、请求与持久化

- 扩展现有 AppModel/MediaAPI 管账号列表、当前空间、用户状态刷新代次与切服。业务仍经 Go 命令，页面不得自行请求 Emby。普通/私密、账号、线路变更使在途请求和图片身份失效；成功、失败与缓存回调都验证代次。
- 私密空间先读取完整当前服分类，缺失或无法确认时拒绝进入。私密请求限制与 Android AppState 对齐；局部显式 server/token 不得绕过当前服约束。退出/切服清理空间和缓存，不落本地历史/搜索记录。
- 收藏/已看/隐藏续播等成功后推进相应刷新代次，当前页与返回页补验；失败不更新 UI 为成功，多页刷新失败保留上一次完整快照。切服/主服/线路操作持久化成功后再发布新身份。
- 核心 prefs 与宿主呈现偏好分开；设置每项必须有真实生效点。账户、设备标识和必要隐私配置继续走既有 Keychain 后端，不因扩页回退到可清理缓存，也不由 Swift 重写 config.json。

### 播放与平台能力

- Aether 会话继续由单个 PlaybackController 拥有；新增分集队列、同季连播、播放内换版本、倍速、画面模式和章节时，共用停止/上报屏障。队列未加载、加载失败和真实季末分别呈现，不能把空初始数组当季末。
- 版本/条目变化清理旧轨道映射；字幕预选和用户手选按真实版本/轨道身份恢复，晚到轨表仍可应用。保留挂起暂停、前台不自动出声及旧 item_id 上报保护。当前引擎能力未验证的字幕/弹幕效果单独实测。
- 通用插件 Go/goja 运行时、声明式原生 UI、网页宿主、JAR/Python 等分别报告能力，不以全局 `plugins=false` 代替研究，也不在未实现时报告 true。插件持久状态、安装来源和缓存恢复要纳入平台方案。
- 手机伴侣复用 Go 服务/配对协议与已有总线导航事件；生成二维码只含配对协议所需信息，不把凭据/媒体 URL 进日志或构建产物。网络、生命周期和手机承接均需真机验证。
- 当前 SDK 27 无可导入的 WebKit，系统文档选择器明确不可用。流影/网页插件的手机承接或电视内替代仍为用户待决；文件导入/备份、Android 存储卷与专有引擎配置按能力映射处理，不宣称直接可移植。

### 交付与回滚

- 预期改动集中在 `apps/tvos` 页面、AppModel/MediaAPI/播放器及对应 Swift 回归；生成绑定仅在实际命令契约变化时改生成器。核心仅修改确实缺少的平台接线，不改变其它端业务。
- 按“导航/浏览 → 管理/聚合 → 设置/私密/扩展 → 播放补齐 → 整体验收”实施，每阶段记录已实现与未验差异。阶段产物不等于整体完成，也不以较小工作量为由删减功能。
- 保留当前已签名技术基线和用户数据；更新安装不先卸载。遵循现有用户出包/安装授权，严格验签后才更新真机；不提交或发布。最终运行验收同时覆盖原 A1–A7 和对齐 A8–A14。

## 数据流与所有权

```
SwiftUI → CoreClient（会话合并/seq/取消）→ lp_call → Go 业务/服务端
                       ↑                   ↓
                 单一事件泵 ← lp_next_event + lp_free
播放请求 → player.play(engine=exo) → PlayResult → AetherEngine
实际位置/状态 → emby.reportProgress / player.stopPlayback → 核心会话
图片 → 核心已鉴权回环数据通道 → 原生图片视图
```

- 地址解析、登录、账号和隐私规则、播放地址、续播决策、服务端上报归 Go；Swift 不新增 Emby HTTP 客户端。
- AetherEngine 读取核心提供的媒体与字幕地址是宿主播放的必要网络例外，不在 Swift 重复业务 API。实际暂停、seek、音轨、字幕、视频/字幕渲染归宿主。
- `engine=exo` 是现有宿主模式的内部协议值，不显示给用户；不传未识别的 aether 字符串，不改其它平台默认引擎。
- 不能沿用探针“每条命令内阻塞读事件并丢弃其它事件”的实现。CoreClient 有唯一持续事件消费者、按 seq 管理多个在途调用、完整处理 result/partial/event/eof；支持对象/数组/标量/null。C 字符串复制后立即 lp_free，包括解析失败路径。
- 发命令、等待和读取事件不阻塞主线程；不在同一个串行队列上用永久事件循环堵住发送/关停。取消通知 lp_cancel，并以路由/会话代次拒绝晚到结果。
- 每次调用统一注入当前 server/token/user_id/device_id。账号更换清空 UI 数据与图片请求；E_AUTH 触发重登，不把网络错误当账号失效。

## 命令与参数约束

| 流程 | 接口与边界 |
|---|---|
| 启动/会话 | ABI 检查 → lp_init → 事件泵 → system.capabilities → emby.currentSession。当前任务只接 Emby，不启用其它源。 |
| 登录/退出 | emby.login 明确包含持久 device_id；普通停播不 emby.logout。显式退出检查 emby.logout 返回的 server_ok，不能把命令成功当成服务端成功；无论该值如何都继续尝试 account.removeAccount(server_id)，并验证持久存储更新。分别反馈服务端与本地结果，本地删除失败不得显示已退出。 |
| 首页 | emby.listResume 与 emby.views 独立请求；保持默认屏蔽与普通内容过滤，不传 include_blocked=true 绕过。 |
| 媒体库 | emby.listItemsPage 的分页/排序字段放在嵌套 query 对象，parent_id 在外层；不能照旧命令表将分页字段放到顶层。保留直属层级，不固定 IncludeItemTypes。 |
| 剧/季 | emby.itemDetail(with_children=false)、emby.seriesSeasons、emby.seasonEpisodes(parent_id,start_index,limit)。保留空季成功与请求失败区别，必要回退沿现有核心语义核查。 |
| 播放版本 | emby.itemMedia 与 player.play(media_source_id)；用户明确选择优先，默认不在 Swift 取 versions[0] 猜偏好。缓存仅预览，播放使用实时最终结果。 |
| 续播/从头 | 普通播放不强灌探针 resume；从头显式 from_start=true，不能用 resume_secs=0 替代。 |
| 上报/停止 | emby.reportProgress(pos,paused,item_id)，player.stopPlayback(pos,item_id)；三次报告共用核心的会话，不让 Swift 自造会话 ID。 |

Page 当前有 items/total；实际后续游标按核心运行时响应与既有分页处理核对，不能凭旧文档假设字段存在。客户端遇到提前空页不无限循环，不把失败吞成“全部加载完”。

## 播放会话

一个场景只持有一个 AetherEngine 会话。开始新条目、退出、重试和挂起收尾串行处理，并绑定条目/媒体源及本次会话代次。播放器状态来自 Aether，而不是未初始化 mpv 的 player.status。

起播成功后定时上报实际位置；暂停/恢复/seek完成立即上报，定时上报同类请求不无限堆积。停止先捕获实际位置、停引擎输出，再等待有界的核心停止报告；失败可返回界面但明确同步状态。旧会话收尾不能落到新会话。

Aether 音轨使用 selectAudioTrack(index: TrackInfo.id)，字幕使用 selectSubtitleTrack(index:) / clearSubtitle()。选择结果异步确认；音轨 reload 需要保持原暂停态和当前位置。外挂字幕由核心返回的资源创建 ExternalSubtitleTrack，使用对应资源鉴权，不将主服 token 随意加到跨源地址。多种 cue 中先实现并验收普通文本，其它类型不伪装成功。

后台/中断先暂停并尽力上报；不能依赖 applicationWillTerminate。通常挂起保留核心实例，不执行 shutdown 后假设能任意重新 init。真正销毁先停引擎/观察者，再关闭核心、消费 EOF；应用不调用 exit()。

## tvOS 存储与隐私（实现首个门禁）

探针根目录随机且卸载即删，不能成为正式存储方案。核心的数据根由宿主明确指定到沙盒可写位置，路径仍统一经 core/paths；该根中的文件不能单独作为账号跨启动保证。

使用 Apple Keychain 为核心必要配置提供平台持久化后端；核心继续拥有序列化、未知字段保留、损坏处理和保存事务，Apple 平台接线负责安全存取字节。优先在现有 ffi 平台边界注入 Go 存取函数，避免跨 C ABI 传回调、增加公共命令或让 Swift 解析/改写 config.json。非 tvOS 继续沿用现有文件后端。

正式应用运行验收前必须验证 Keychain 真机存取、数据量/失败处理、保存与返回成功的一致性，以及账号/设备标识/隐私必要设置的恢复。若不得不改变上述所有权或公开契约，回到设计评审，不能用“启动/退出时复制 config 文件”绕过所有保存路径。

缓存和临时字幕允许被清理，可重建内容不写进 Keychain；本地历史不承诺跨系统清理保留，以实时服务端续播为本阶段验收。恢复不到隐私设置时禁止浏览，不用默认普通列表顶替失败的恢复。退出账号须更新同一持久后端，缓存清空后不能复活旧 token。

Apple 官方存储材料为历史指南，当前 tvOS 27 的 Keychain 行为及宿主接线仍需实测；这项技术门禁不能由规划通过代替。

## 网络与日志

保留用户授权的 HTTP 局域网使用。对核心回环资源与用户提供的媒体地址分别核查 ATS/本地网络权限；不直接复制探针配置作为已验结论。固定 IP 的 HTTP 流不能仅凭 NSAllowsLocalNetworking 就断言可用。

确需媒体访问例外时采用平台允许的最小范围并记录实际产物；不改变 HTTPS 默认验证，不新增全局信任自签证书。Aether URLSession 与核心 Go 网络栈的权限和证书行为分别验证。

不记录命令完整参数/响应、播放 URL、请求头、Keychain 数据或字幕来源地址。关闭/脱敏 Aether 自带日志输出后再用真实账号联调，错误向用户只显示中文类别与可操作信息。

## 构建、回滚与交付

依赖锁需记录固定源码修订、二进制来源、上游校验信息与许可；上游无独立哈希时明确本地计算哈希的信任边界。现有忽略目录中的 tarball 仅作缓存，不是入仓复现入口。可选能力关闭；保留上游与依赖许可声明。

沿用真机已验 GOOS=ios/arm64/c-archive 配合 tvOS clang target，保留完整核心引用的 MPVKit 1.1.0-n9.0.2 静态依赖闭包（28 个切片含文件型 MoltenVK）。本轮不为减少体积删除 Go/mpv 编译路径。静态归档以 -load_hidden 隔离，并对最终可执行文件核查符号；Aether 动态框架按 Xcode 规则嵌入和签名。

工程及 scripts 新入口不硬编码 SSH 别名、设备/Team ID、签名身份或本机路径。目标真机优先；不因首轮建立工程而下载模拟器。生成检查和必要测试与正式打包分开，未获直接出包要求不自动打包安装。

仅在产品实现形成后更新 Apple 平台说明、目录/构建规范及开发入口；Android TV 正本不重写为 tvOS。新 app 与平台条件分支可以独立回退，现有桌面/Android 行为不变。当前计划不自动提交、发布或归档前置探针。

## 早期最小版阶段的技术说明（2026-10-18）

最小版随后已签名安装，首装空会话故障已修正，用户确认可以启动；详见验证记录。Keychain 独立进程试验不能替代正式应用验收，完整跨进程/清缓存恢复及浏览/播放门禁仍未完成。

固定 IP 的 HTTP 媒体和外挂字幕经 Aether URLSession，服务器地址运行时任意输入，不能预列域名；Info.plist 因而使用 NSAllowsArbitraryLoads，并保留 HTTPS 默认信任校验。这是覆盖应用 URLSession 的 HTTP 例外，不宣称仅局域网放行；实际网络行为尚未验收。

固定依赖准备保留源码包的许可资源并禁用 Aether 中央日志出口；源树/28 切片/许可资源在使用前复验。最小版最终链接/签名已通过；全网络首次获取、MPVKit 静态闭包完整发行材料与正式运行验收仍未完成。
