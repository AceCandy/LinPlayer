# tvOS 客户端：与现行 Android TV 对齐

## 目标

以当前 Android TV 正式入口共享的手机页面、功能与品牌视觉为产品基准，在 Apple TV 上实现一致的导航、浏览、管理与播放体验；只因遥控器、横屏和经核实的平台能力作必要适配。

本任务独立于前置技术探针。早期最小闭环已建立、签名安装，用户已确认修复后能够启动；完整真机验收仍未完成。用户随后指出其与现有产品不同，并明确要求按现行 Android TV 对齐。此前“只做最小客户端”的产品裁剪由本次要求替代，不将继续补齐功能视为范围外需求。

## 背景与依据

- 当前产品没有正式 tvOS 工程。现有共享规范的“苹果暂不做”由用户本次 tvOS 授权作有限例外，不扩展到 iOS/macOS。
- 前置任务 `../10-17-appletv-playback-spike/research/aether-core-resume.md` 证明 Go 核心 + AetherEngine 7.39.0 的指定 SDR 样本起播、暂停/恢复/跳转、服务端进度保存及新进程续播可行。
- 用户确认颜色和声音正常的证据来自独立引擎探针；不替代正式界面的人工验收。
- 当前 Android TV 入口为 `TvRoot → PhoneRoot(tv=true) → MainShell`，正式页面来自 `ui/pages`，不是旧 `tv/HomePage.kt` 等独立浏览页。tvOS 使用 SwiftUI 重建同一产品，不要求复用 Compose 源码或机械换算 dp；逐页证据见 [对齐矩阵](research/product-alignment.md)。
- Apple 文档明确本地文件不保证跨启动存在。账号恢复、设备标识与隐私配置必须独立于可清理缓存验证，不能沿用探针 UUID 数据根。

## 范围与要求

| 编号 | 要求 |
|---|---|
| R1 | 服务器地址、用户名、密码登录，保留当前账号；错误可读、可重试。提供退出账号入口，普通退出播放或应用挂起不注销账号。 |
| R2 | 首页按现行共享首页对齐横幅、媒体库、继续观看、各库最新、合集和可用插件栏目；各区独立加载。媒体库按真实层级分页浏览，支持对应排序/筛选，返回恢复卡片焦点和滚动位置。 |
| R3 | 详情对齐现有资料、收藏/已看操作、版本/线路、字幕预选、季集、相似内容及媒体信息；播放/继续与从头的语义保持。正文不等待播放信息加载完才显示，下载沿用 Android TV 的隐藏规则。 |
| R4 | 播放由 AetherEngine 承担，支持暂停/恢复、定位、选择实际可切换音轨、文本字幕选择与关闭。只显示真实能力。 |
| R5 | Siri Remote 可完成全部主流程；面板关闭恢复焦点，返回逐层处理，根页返回交给系统。 |
| R6 | 播放位置由实际引擎读取并交核心上报；显式退出保存进度，新进程按核心决策续播。挂起立即暂停并尽力上报，回前台不自动出声。 |
| R7 | 重启和系统清理缓存后可恢复账号及稳定设备标识；恢复失败必须明确报错，不能静默生成空配置或放宽媒体隐私过滤。 |
| R8 | 凭据只经运行时输入与平台安全存储；日志/测试图/构建产物不包含实际地址、token、密码。支持已授权 HTTP 局域网使用，HTTPS 默认校验证书。 |
| R9 | 工程、固定依赖、绑定生成与检查入口可入仓复现；工具链、下载库、签名身份及运行数据不入仓。构建/真机更新沿用已有用户授权，未获指令不提交或发布。 |
| R10 | 顶部导航与当前 Android TV 一致：当前服务器、首页、收藏、聚合视界、搜索和设置；媒体库从首页下钻。栏目保持各自路由、列表和焦点状态；详情/播放遵循全屏层级。 |
| R11 | 搜索支持当前服与聚合范围、真实类型/历史条件及分页；收藏支持现行分类、排序、分页和状态更新。所有操作使用已有 Go 命令，不另写业务 HTTP 客户端。 |
| R12 | 聚合视界按服务器分组呈现统计/续播，保留排行榜与日历入口；切服再开详情保持账号、线路和页面身份一致。不是另造合并去重影片池。 |
| R13 | 服务器管理覆盖添加/切换/编辑/删除、探测、聚合及主服选择；线路覆盖编辑、同步、测速、切换。换服/换用户/切线路都重建必要身份并拒绝迟到请求。 |
| R14 | 设置按现行共享设置分类逐项核对，已有核心配置须真实读写且产生效果；mpv/Android 专属项须按 Aether/tvOS 实际能力明确适配，不画能保存却不生效的开关。 |
| R15 | 私密空间继承当前服分类校验、普通/私密过滤、跨服与本地记录限制、入口及退出、主题与身份缓存隔离；进入失败保留普通空间，不默默放宽过滤。流影承接方式属于待决平台差异。 |
| R16 | 播放对齐当前 TV 的选集/同季下一集与开关、播放内版本切换、倍速、画面模式、章节、轨道与字幕选择记忆、片头片尾偏好。实际引擎能力不足须逐项记录，不通过调用 mpv 命令假装控制 Aether。 |
| R17 | 插件/扩展、手机伴侣、文件浏览和导入导出逐项做平台能力映射；通用 Go/JS 业务不因宿主重写而默认移除。依赖 WebView、Android 运行组件、存储卷或专用引擎的部分，须有实际证据和明确替代/差异结论。 |

## 明确不做

不新增现行产品没有的功能，不修改 Android/桌面的行为，不扩展 iOS/macOS，不发布到 App Store/TestFlight，不自动提交。TV 继续隐藏下载，不移植手机专属触摸/PiP/截长屏交互，不把 Android 引擎选项原样用于 Aether。签名和真机更新继续沿用已有用户授权。

插件、弹幕、本机文件及网页入口不再因早期最小版排除项被整体删除；按 R14/R17 的能力映射和平台决策处理。平台替代的待决项不属于已经批准的删减。

HDR/DV、对象音频、复杂 ASS/PGS 和长期稳定性列专项验证；首轮以 SDR、常用音轨和文本字幕为验收样本，不宣称全格式支持。

## 验收标准

- [ ] A1（R1、R7）：首次登录成功；全新进程免登；清理可重建缓存后账号/设备标识仍可恢复。持久化失败、损坏和凭据失效不会静默重置。
- [ ] A2（R2、R5）：遥控器从首页进入真实媒体库，翻至后续页、打开详情再返回，焦点与滚动位置恢复；空库和失败有不同反馈。
- [ ] A3（R3）：电影能按选中版本播放/续播/从头；剧集能切季并选择后续页分集；旧请求晚到不覆盖新季，缓存资料不用于过期播放决策。
- [ ] A4（R4、R5）：用户在正式播放页人工确认 SDR 画面、颜色、声音；遥控暂停/恢复/跳转后位置正确。实际切换双音轨、选择/关闭文本字幕，不能仅以轨道数量通过。
- [ ] A5（R6）：显式退出后的服务端读回位置与实际停止位置相符；新进程自动选择服务端位置并实际前进。挂起/唤醒不会重复播放、自动出声或将旧上报写给新条目。
- [ ] A6（R5、R8）：面板返回仅关闭一层，根页交系统；断网、令牌失效和无可播流有真实反馈。普通内容过滤及不同身份缓存隔离有效。
- [ ] A7（R9）：固定版本可复现、Swift 绑定与真源一致、核心静态符号隔离检查通过；其它端相关门禁通过；明确列出签名/安装/真机中尚未执行的项目。
- [ ] A8（R10）：用同一账号/内容对照实际 Android TV，顶栏入口、首页层级、海报/横幅、详情与面板有真实渲染对照；遥控往返不丢各栏焦点和滚动。
- [ ] A9（R2、R3、R11）：首页栏目、库排序/筛选、搜索、收藏、详情状态与字幕预选可操作；写入失败保留原状态，成功后当前及返回页面正确刷新。
- [ ] A10（R12、R13）：至少双服务器验证聚合统计/续播、切服开详情、管理账号及线路；不会把旧服图片、列表、凭据或上报交给新服。
- [ ] A11（R14）：设置逐项具有读取来源、写入命令/本机偏好归属、实际生效点和验证结果；所有平台差异可追溯，无假成功控件。
- [ ] A12（R15）：正常/私密切换、分类缺失拒绝进入、换服退出、跨服/历史/插件限制及图片缓存隔离真实有效；网页承接按最终平台决策验收。
- [ ] A13（R16）：同季三集切换/完播、关闭自动下一集、季末、队列慢/失败、版本/轨道记忆、倍速/章节/画面模式均经真实页面与针对性回归验证；进度另读服务器确认。
- [ ] A14（R17）：对齐矩阵每项标明已实现、已验或用户确认的平台差异；不得以阶段性导航/首页完成宣布整体对齐。插件/伴侣/文件的承接方式按最终方案实测。

## 待决平台处理

- 当前 SDK 27 的 tvOS 类型检查确认 `WebKit` 模块不可导入，系统文件选择器不可用。流影/网页插件的电视内体验或手机承接方式已询问用户，仍待答复。原生页面、核心业务和遥控适配的对齐目标已经授权。
- Android 存储卷、mpv/Media3 配置与 JAR/Python 运行组件不自动等价于 tvOS 能力；实现前补齐逐项方案，不能以未知当作已支持或默认删除。
