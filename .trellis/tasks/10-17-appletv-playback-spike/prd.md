# Apple TV 最小播放可行性验证

## 目标

验证 LinPlayer 能否在 Apple TV 上通过 Go 核心取得 Emby 播放地址，完成起播、拖动、字幕切换和进度上报，为后续 tvOS 客户端提供可重复的技术依据。

## 已确认事实

- 用户已同意先做最小播放验证；不代表要求完整平台功能或商店发布。
- 现有产品范围是 Windows、Linux、Android 手机和 TV；本任务探索 tvOS，不把探索结果写成已支持平台。
- 当前工作环境是 Linux；用户已确认有 Apple TV 真机及局域网内的远程 Mac。SSH 非交互连接已恢复；Mac 为 Apple Silicon，用户已将系统更新到 macOS 14.8.9。
- Xcode 16.2（16C5032a）并排安装于 `/Applications/Xcode-16.2.app`，首次初始化检查返回 0，tvOS 18.2 SDK 查询正常。旧版 15.4 保留，通过 DEVELOPER_DIR 明确选择新版。Homebrew 已存在。
- Apple TV（AppleTV14,1 / tvOS 27.0）已重新配对；新版 Xcode 的 xcdevice 显示 available true，CoreDevice tunnel connected，DDI 服务查询成功。最小 Go C ABI 应用返回 GO_TVOS_PROBE=42；随后完整核心、libmpv、OpenGL ES 与真实播放闭环也已在真机执行，详见当前结果及研究记录。
- 用户已授权安装必要开发工具。Go 1.27.2 已安装到远程用户目录 `~/Developer/LinPlayer/.toolchain/go1.27.2`，下载文件经官方 SHA-256 校验，`go version` 运行成功；未改全局 PATH。
- 已有 C ABI 和宿主负责解码的播放模式，没有正式 tvOS 产品工程。本轮临时 UIKit / GLKit 探针验证了完整核心及 libmpv 渲染通道，不构成正式平台支持。初查代码证据见 research/core-feasibility.md，后续实测见 research/full-core-build.md。
- 临时最小 Go C ABI 探针先在 tvOS 17.5 模拟器返回 42，再使用 Xcode 16.2 / tvOS 18.2 SDK 在 tvOS 27 真机 UIKit 应用内返回 42。该最小探针过程见 research/tvos-abi-probe.md；完整核心、libmpv 和播放的后续结果单独记录，不扩大早期探针结论。

## 范围与要求

- 第一关验证目标 tvOS 工具链、Go 运行时和 C ABI 链接、初始化与事件消费；必须有实际运行证据，不能用 macOS 构建成功替代。
- 第二关验证真实 Emby 会话下的起播、暂停、拖动、字幕切换和停止；播放器方案待第一关和平台兼容性调查后确定。
- 第三关验证播放进度、停止上报及再次打开的续播位置，区分模拟器和真机结果。
- 账号、媒体地址和签名材料仅通过本地配置提供，研究记录与提交内容不含其实际值。
- 本轮不包含完整媒体库界面、全部附加功能、应用商店发布，也不承诺所有格式、HDR 或音频输出能力。

## 验收标准

- [x] 在明确的 Xcode、tvOS SDK、Go 版本及设备条件下，能重复构建并安装验证程序。
- [x] tvOS 宿主能完成 ABI 版本核对、核心初始化、命令结果与事件消费、内存释放及退出清理。
- [ ] 通过核心取得 Emby 播放信息，指定测试片源能显示画面和播放声音。
- [ ] 暂停、恢复和拖动后画面及播放位置正确；字幕切换结果可观察。
- [x] 指定有明确时长的 SDR 电影停止后服务端保存正确位置，新进程与全新数据根可续播。AetherEngine 整合后停止约 126.000 秒，读回 126.000 秒；新进程未传起点，核心采用 126.000 秒，实际播放到约 135.197 秒。服务端自报兼容版本 v4.8.10.0；未知时长分集仍另记失败场景，不推广至所有媒体。
- [x] 分别记录已通过、失败及未验证的设备 / 媒体场景；不将静态审查或模拟器结果视作真机验收。
