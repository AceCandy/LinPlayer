# 首页海报动效对照

## 目标
依据用户提供的 Yamby APK，增强手机首页海报入场的可感知性，保留重复横滑反馈与已有浏览交互；尝试容器中的 Android 模拟器进行同数据对照。

## 范围
- 首页真实海报按已确认横向列表动效调整，不阻塞正文、图片加载和滚动。
- 保留导航返回位置、账号隔离、共享海报、点击/长按和系统减少动画行为。
- 收藏、媒体库、详情及播放器本批不调整；服务端生产实现不改。
- 模拟环境只用本地假数据，记录模拟器与真实手机验收的差别。

## 验收
- [x] 实际 LpRow 的动画中间帧具有明显缩放、右侧归位和错峰，标题与排布局稳定。
- [x] 反复横滑已有图片仍有位置反馈，不重复请求图片，导航返回不重播。
- [x] 冷图、快滚、账号变化、系统零倍率与点击/长按回归通过。
- [x] 尝试运行 Yamby/LinPlayer 模拟器对照，记录成功路径和环境限制。
- [x] 独立复核、关联门禁和手机 APK 验签通过，清理本轮临时产物与服务。

## 仍待真机验收
- 手机ARM64包的主观观感及滚动帧耗时；模拟器UI验证不代替此项。
- 本轮不提交、不归档；任务保留，便于用户验收后收尾。
