# 验证播放体验并定位 TV 高码率退出

## Goal

在真实设备上补齐播放体验验收，并依据退出现场确认和修复 TV 高码率退回详情页的问题。

## Context

- 详情 PlaybackInfo 复用、Media3 拖动、MPV 缓存缩略图、依赖核对、磁盘缓存扩容与退出日志已完成代码审查和自动回归。
- TV 高码率退出只有现象描述，尚无设备型号、实际播放内核和复现日志；缓存扩容与日志补齐不等于修复故障。
- 本机未连接 Android 设备；SDK 可用、单测可执行，与真机验收区分。

## Acceptance Criteria

- [ ] 记录 TV 型号/内存、播放内核、缓冲设置、发生阶段；复现并关联 tv_start、tv_leave、tv_lifecycle_stop 与 process-exit 的时间及退出原因。
- [ ] 根据证据区分主动离页、进程回收、解码异常及原生崩溃，实施有针对性的修复后以同一影片/设备回归。
- [ ] 真机验证 Media3 松手精确跳转、取消恢复、换集不残留及播放恢复；验证 MPV 已缓存位置缩略图和未缓存位置仅显示时间。
- [ ] 同设备、同影片、同网络与 Hills 对比首开/二次打开的首帧耗时，记录结果与限制，不将单测视为等速证据。

## Constraints

- 不根据相似公开 issue 或文件大小直接认定 OOM。
- 诊断文件留在本地受保护位置，提交只记录脱敏结论；不得记录媒体地址、账号或鉴权信息。
- 需要出包或设备安装时遵守当次用户授权。
