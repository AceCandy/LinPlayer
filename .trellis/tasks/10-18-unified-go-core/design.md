# 统一展示缓存设计

各端只消费 Go partial 展示旧资料，result 保持实时；账号、服务器、空间、查询、屏蔽版本共同隔离。普通与私密统一持久化，不沿用旧桌面“私密仅内存”特例。

- Go displaycache 是展示快照键、投影、预算、持久化和失效的唯一实现。身份散列前缀支持同账号/空间状态写入后失效；请求散列后缀保持查询隔离。旧版本键自然冷失效，旧宿主缓存不导入。
- emby.cachedItems 只读核心候选池。成功浏览结果由核心合并，按 ID 去重；稀疏 setPlayed 更新只更改已知条目。候选池与请求快照共用1000条/每条512KiB预算，未知字段、地址与凭据不入池。
- setPlayed/setFavorite/hideResume 成功后失效当前身份请求快照，保留候选池；generation 阻止旧读回写，独立 cleared 代次阻止清理前写操作重建候选。并发状态确认串行完成失效与候选更新。
- seasonEpisodes(all=true) 将桌面既有全季分页聚合搬到核心。默认模式仍按页返回，后页失败不发布半份结果，缓存只供预览、实时结果用于目标决策。
- Android 移除 BrowseCache/DetailCache，首页、库与详情直接 displayBlock；页面留存、图像解码、轮播位置保留。启动后台清理废弃宿主缓存目录。
- 桌面移除 MetaCache；首页两路 partial 保存在本次页面请求状态中，ResumeFeed 保留失败侧并显示真实错误，合集/库/季集统一消费核心快照。
- tvOS 库分页/筛选、搜索/聚合、收藏、发现、人物、合集均补充 snapshot；分页游标只由实时结果推进，失效错误清展示和对应分页状态，取消和身份变化拒绝迟到更新。

边界：此任务完成展示缓存与相关聚合的源码迁移，不代表各端全部UI、播放器、系统接入已合并；这些平台职责继续留在各端。原 tvOS UI 对齐与真机验收任务独立保留。
