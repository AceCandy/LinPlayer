# 精简播控并修复弹幕加载与显示

## Goal

精简手机按钮背景和倍速操作，移除各端播放器选集列表入口，修复配置弹幕源后的自动加载并参考本地客户端实现。

## Requirements

- 手机播放控件去掉按钮独立半透明背景，保持点击区域、状态反馈及亮画面对比度。
- 手机倍速点选范围为0.75至3.25，步长0.25；弹窗比当前更窄；加减每次0.1。
- 各端播放器移除选集列表入口和对应独占快捷键，保留上下集、连播、章节及详情页选集。
- 配置可用弹幕源且开启弹幕后，进入播放自动匹配加载；尊重关闭状态、来源与匹配记忆，避免换集迟到响应污染。
- 弹幕加载和手机操作参考本地Yamby/Hills已有证据，不能将静态文案当作已实测行为。
- 恢复手机、TV、桌面弹幕四项常用设置：显示区域、不透明度、字体大小、弹幕速度；三种行数继续隐藏。
- 按实际字宽居中和滚动，修复偏心、尾部骤失；区域约束三种弹幕，底部固定贴区域下沿。调整区域时解除旧行数限制，保留其它偏好及旧API。

## Acceptance Criteria

- [x] 手机横竖屏按钮无独立底色，亮暗背景可辨且交互范围不缩小。
- [x] 倍速列出11档，点击和0.1加减实际提交正确；边界不越界、读数无浮点噪声。
- [x] 桌面、手机、TV及tvOS播放器无选集列表入口；上下集和章节仍可用（tvOS仅静态核查，设备验收见限制）。
- [x] 弹幕自动加载问题有能复现旧故障的回归，覆盖关闭、换集及来源错误的相关边界。
- [x] 完成针对性测试、实际渲染及独立复核，明确未做的设备/实服验证。
- [x] 四项样式可操作，失败保留已保存值；四档区域的混合类型边界/防重叠和实际字宽渲染有回归。

## 范围限制

恢复既有常用外观项，不恢复高级行数菜单，不做自动识别片头片尾、不改详情选集；不出包或安装。用户已授权修复、独立审核后提交并归档，不推送。

密度取舍：本次保留整段占轨防重叠。核心未知宿主实际字宽和视口比例，不能用估宽缩短占轨造成长句/窄屏追尾；恢复安全同轨复用需另行扩展测量回传与重排契约，不在本次修复中冒险放宽。
