# Android TV 视频对照体验修正

## 目标
依据用户提供的 SenPlayer 与本应用实拍视频，让电视浏览稳定、紧凑、焦点清晰；复用手机业务，不照搬手机尺寸和入场动效。

## 已确认依据
- 2026-10-28 用户提供两段视频并逐项反馈，随后认可按顺序推进。对照以实际画面为准，不将参考应用的背景算法或性能实现作为已知事实。
- 视频中本应用存在整行栏目高亮、海报片名白条、重复淡入、置顶导航遮盖内容、详情上返首屏不完整。
- 用户另外报告详情连续返回有时退出桌面、收藏切回首页首屏不完整；视频没有完整记录这些过程，须复现。
- 上轮测试仅覆盖部分路径和测试素材，不能代表真机连续浏览验收。

## 范围及顺序
1. R1 返回层级与回顶：10-28-androidtv-navigation-return。
2. R2 滚动图片与动效：10-28-androidtv-scroll-motion，依赖 R1 保持滚动及导航语义。
3. R3 首页焦点、密度与导航：10-28-androidtv-home-density，依赖 R1/R2。
4. R4 详情排版与背景延展：10-28-androidtv-detail-atmosphere，依赖 R1/R2/R3。

## 跨阶段验收
- [x] 返回只退一级，弹层先关闭，栈底保留首页；根页退出与详情退页分离。
- [x] 详情内部上返主操作完整展示首屏；详情退出恢复来源卡片及位置；收藏切首页完整展示首页。
- [x] 已展示图片上下往返不重播加载式淡入；不扩大缓存、不关闭手机动效来掩盖问题。
- [x] 无粗焦点框及片名白条，按钮反色微放大、海报整体轻微放大，焦点可见且不会被裁切或困住。
- [x] 栏目入口紧凑靠左、下行到首张；海报按 TV 实际窗口自适应、收紧两侧留白。
- [x] 首页导航随首屏离开视口；主栏目获焦切页、首页确认刷新，不因获焦重复刷新。
- [x] 详情文字与按钮收紧，沉浸背景延展连续；浅色、深色及大字号仍可读。
- [x] 保留显示/隐藏媒体库、续播有/无四组合；共享手机组件回归无行为变化。
- [x] 每阶段独立复核并记录已验/未验，最终整条路径复测；无真机数据不宣称性能达标。

## 不做
不重写浏览栈、核心 API、播放参数或缓存架构；不变更私密隔离、插件权限和手机交互；不自动打包、安装、提交或推送。单季季海报区只列候选优化，本轮不删除既有功能。

## 风险与待验证项
录像安装版本、实体遥控重复事件、真实服务器请求与帧耗时未核实；实际过扫描和远距离字体可读性需设备验收。记录不得包含账号、服务器地址或视频原始隐私资料。
