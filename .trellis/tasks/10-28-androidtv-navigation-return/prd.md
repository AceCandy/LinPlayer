# TV 返回层级与首页详情回顶

## 目标
返回始终遵循页面层级，完整恢复用户期望的可见区域，同时保留来源海报位置。

## 依据
- SharedBrowse.kt:145 的 SharedTvNavigation 先 popBackStack 再判断栈底，exitAt 未随成功退页重置；是待回归确认的风险，不能写成已复现的遥控穿透。
- HomePage.kt:173 的 returnToNavigation 仅由内容向上退出触发；SharedBrowse.kt:134 主栏目获焦切页没有明确的首页完整回顶契约。
- DetailPage.kt:1085 只为非剧集、非合集参数组向上退出提供回顶；视频中剧集约 8-11 秒上返仅露操作区。
- 证据文件均位于 apps/android/app/src/main/kotlin/xyz/linplayer/app/，当前起点 109bd236。

## 需求与验收
- [ ] R1.1 详情返回一次回来源页；弹层打开时先关闭弹层；加载中也可返回。
- [ ] R1.2 栈底返回第一次保留可见首页并提示，随后两秒内另一独立返回才退出；进入其它页或成功退页不沿用此前退出计时。
- [ ] R1.3 从剧集分集、季和演员区域向上回主操作时，头图顶部、标题与按钮恢复到初始坐标；电影/单集参数上返继续成立。
- [ ] R1.4 从收藏获焦切回首页完整展示头图；头图异步到达也不留下半屏位置。
- [ ] R1.5 详情返回恢复原海报和原列表位置；不能被 R1.4 的回顶覆盖。
- [ ] R1.6 首页四种媒体库/续播组合及多卡横滑路径均可按键上下往返；保留导航获焦切页，不把首次加载或异步刷新变成抢焦点。

## 不做
暂不调整海报尺寸、字体、背景、顶栏滚出或刷新入口；不动 TV 播放器退出语义、手机导航、核心请求及权限。

## 未确认技术事实
实体遥控是否重复派发返回尚无证据；先用真实 TvRoot 和标准按键重现，不预设全局防抖或修改 Activity 输入分发。
