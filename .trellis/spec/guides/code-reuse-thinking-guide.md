# 复用与变更传播检查

- 修改前先用 CodeGraph 定位现有符号、调用链和相关工具；常量 / 文本用精准 rg，避免扫全仓与产物。
- 此能力是否已由 libmpv、平台原生 API 或现有组件提供？
- 被改函数是否共享给桌面、手机、TV？同一功能有哪些按钮、长按、返回或快捷键入口？
- 相同 JSON 字段是否已在拥有者解码？能否复用现有解析，而非每个页面复制判断？
- 共享提取是否真减少重复并保持语义？单次使用不造接口或通用框架。
- 改动是否产生孤立 import / 字段 / 函数？只清理本次产生的孤立内容。
- 生成绑定和原始命令表是否同步？不要手改生成文件。

实际执行规则：[核心边界](../backend/directory-structure.md)、[共用组件](../frontend/component-guidelines.md)、[JSON 边界](../frontend/type-safety.md)。
