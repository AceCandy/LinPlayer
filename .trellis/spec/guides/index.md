# 思考检查入口

所有任务读取本入口；具体编码约束在 shared / backend / frontend，本文只提供检查问题。

| 场景 | 检查表 |
|---|---|
| 改共享函数、常量、JSON 解析或组件 | [复用与变更传播](code-reuse-thinking-guide.md) |
| 改命令、事件、持久化、API 或跨端流程 | [跨层数据流](cross-layer-thinking-guide.md) |

## 独立复核

- 对审查意见按 file:line 抽查源码，区分事实、推断与未确认内容。
- 核对输入来源和信任边界，不为无法触发的风险堆兜底。
- 读既有中文注释，确认被建议删除的逻辑是否承载真实约束。
- 将真实故障带入测试；若删掉目标功能测试仍绿，重新核查断言。

具体规则见 [开发纪律](../shared/development.md)。
