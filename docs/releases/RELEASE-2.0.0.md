# LinPlayer 2.0.0 发布说明

> 这里维护 2.0.0 的版本概述。每次构建的提交清单由 `scripts/release-notes.sh`
> 从提交历史生成并附在下半段。

## 先说重要的:这一版删掉了几项功能

| 删掉的 | 升级时会怎样 |
|---|---|
| 插件系统(插件、扩展组件、插件页面、插件主题与壁纸) | 插件不再加载，已保存的插件数据源账号在升级时删除 |
| 本机文件浏览(本机文件夹源) | 本机文件夹账号在升级时删除，不删除媒体文件 |
| Windows 外置补帧(RIFE / DRBA) | 移除下载、安装管理与播放选项，不再加载组件；已有组件文件不自动删除 |
| Trakt / Bangumi 账号连接 | 已保存的连接在升级时清掉 |

**没有动的**:Emby 浏览与播放、聚合搜索与跨服换源、排行榜、追剧日历、弹幕、
下载、预取与多线程加载、跳过片头片尾、备份与还原、扫码搬迁、Android 内建 OpenCL 补帧和其它画质增强。

## 设置更简洁

- 「更新」并入「关于」:版本、检查更新、更新渠道、启动时自动检查、GitHub 代理都在这一页。
- 去掉了插件、扩展组件、文件浏览与账号连接相关的入口,分组随之收拢。
