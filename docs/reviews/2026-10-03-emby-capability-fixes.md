# Emby 服务端能力限制修正

日期:2026-10-03。范围:只修改 LinPlayer,未修改 MediaStationGo,未提交、推送或发布。

## 基准与识别

- LinPlayer 基础提交:`c4c97819a80489258166696ca39ae75bc1095e97`。工作树包含此前产品规范修正,本次保留。
- MediaStationGo 基础提交:`6e202521ac6a6990b78c6bca53afc10a99584688`。核查时已有红果业务、测试、Trellis 记录和 API catalog 差异,本次未改动该工作树。
- 当前实现以固定服务端标识识别限制,不按显示名称或空数组推断。标识依据为 MediaStationGo `internal/service/emby_compat.go` 与公开系统信息 handler。
- 登录探测、媒体列表与详情返回的身份会复用到服务器级缓存。仅附加能力路径必要时做一次只读探测,普通列表与起播不新增该探测。并发探测合并、等待可取消,缓存最多 64 项;成功身份缓存 5 分钟,未知状态缓存 10 秒。
- 能力信息是已核实的兼容限制,不替代用户权限检查。缺省能力字段保持其他 Emby 的既有行为。

## 修正内容

| 路径 | 当前基准下的行为 |
| --- | --- |
| 条件筛选与 StudioIds | 核心明确拒绝,不做全库扫描,不返回忽略条件的结果。桌面、手机与 TV 收起或禁用条件控件,保留排序与分页并说明原因。详情标签保留展示,停止跳入不可用筛选。 |
| TMDB 精确查询 | 明确返回不支持,不再拿普通列表的一页做复筛后伪装成功。 |
| 名称搜索与跨服匹配 | 保留已有结果与身份核对;提示名称搜索可能遗漏不同译名。带限制提示的空结果保留,不将其解释为完整查询后不存在。 |
| 隐藏继续观看 | 核心拒绝且不发写请求;桌面菜单禁用并说明原因,手机不提供该操作。 |
| 刷新元数据与扫描媒体库 | 核心拒绝且不发无路由的写请求。 |
| 合集、相似推荐与章节 | 不请求占位接口,返回空集合供既有入口收起;详情返回能力限制供客户端区分原因。手动跳过设置保留。 |
| 权限与协议 | 继续查询真实用户权限;能力、搜索 warning 为可选字段。命令名称与现有客户端契约保留。 |

## 回归与独立复核

- 核心回归先在原实现实际失败:受限场景产生 14 次无效请求,多项操作假成功。修正后无效请求计数为 0。
- 名称相同但身份不同、身份空值、公开探测失败均保留通用 Emby 请求行为;并发筛选只发一次公开探测,另一服务器不会继承限制。
- 新增身份竞态回归先失败再修正:媒体响应已确认身份后,晚到的失败探测不能将其覆盖为未知。相关 Emby、aggregate、datasource 测试与 race 检查通过。
- `scripts/check-core.sh` 完整通过,包含核心测试、出库、FFI/C# 契约及差分对账。`scripts/check-bindings.sh` 通过,303 条导出契约一致。
- 桌面使用真实 Go 动态库、Avalonia/Skia 控件验证:条件控件禁用、排序保留、限制提示可见且无无效分面请求。故障注入重新启用控件后测试实际失败,恢复后通过。
- TV 使用 Compose/Robolectric 真实控件与遥控确认键验证:限制提示可见,状态/年份筛选收起,排序仍在。撤掉限制提示后断言实际失败,恢复后通过。定向 TV 焦点与字幕测试共 13 条通过。
- Android 完整 `testDebugUnitTest` 通过:21 个测试套件、186 条测试,零失败、零错误、零跳过。
- 独立源码复核覆盖核心缓存、限制调用、搜索降级及三端入口。复核后 Android 请求构造增加已知能力保护,不携带已知不支持的旧条件。尚未知身份时仍由核心探测并拒绝,不会发送无效条件或触发全库扫描。桌面受限响应替换为空分面选项,选值回到默认并重新查询。
- 风格门禁、workflow 门禁与包含未跟踪文件的凭据检查通过。存量告警未扩大本次范围。

## 剩余风险

1. 能力描述针对当前核实实现。MediaStationGo 后续补齐接口或改变语义时,需重新核实并更新限制,否则新能力仍会被关闭。
2. 身份探测失败或取消时按未知处理,保持通用 Emby 行为,可能继续请求当前服务不支持的接口。不会用名称猜测并误禁用其他服务器;已缓存的明确身份不会被晚到失败覆盖。
3. 首次恢复旧筛选且身份未确认时,可能先收到一次明确的不支持错误,随后分面返回清除旧条件并重查。核心拦截保证不向该服务端扫描全库或忽略条件伪装成功。
4. 现有依赖安全与编译告警仍需独立维护;本次未进行无关依赖升级。
