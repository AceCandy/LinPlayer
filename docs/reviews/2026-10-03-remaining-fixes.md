## 回归验证

- 完整核心门禁:Go vet、全部包测试、真实出库、FFI 契约、C# 契约、18 条差分、插件 CLI 正负例、绑定与 UI 运行时生成物、规范覆盖及三端接线。
- 绑定门禁:303 条命令的生成物、C#/Kotlin 编译、与 Go 注册表双向比对。
- Android 六组针对性测试共 8 条通过:字幕关闭与匹配、故障建议、通知停播进度、长季分页、出站脱敏。
- 规模测试引用真实 BrowsePage/DownloadPage;使用开发环境无窗口图形后端,不代表真实设备布局和焦点验收。
- 新门禁和关键测试做过真实负例:同名结构串字段、忽略提交核对、关闭虚拟化、忽略字幕关闭、丢弃错误建议、拒绝相对文件名、跨服进度不参与决策;恢复后重跑通过。
- 工作流、风格、秘密扫描和 diff 检查作为交付前检查,不扩充已有秘密基线。
- 签名补充验证:本地真实密钥签名、固定公钥验签、OpenSSL 独立验签,签名缺失、错误公钥、篡改及标签重放;相关包竞态测试与更新后的完整核心门禁通过。
- 局域网风险确认执行实际页面 API 函数;反向关闭确认后测试变红,恢复后登录、批量解析、批量添加及普通遥控检查通过。浏览器弹窗和真设备视觉验收仍未执行。

## 外部配置与未验证范围

1. **更新签名线上配置已执行。** Actions Secret 已通过标准输入配置并核查元数据;仓库外本机备份已核对权限及内容,仍需离线或独立存储备份。接入说明见 [更新签名](../UPDATE_SIGNING.md)。公钥已固定,不接受网络或设置替换。旧未签名发布只能手动安装。
2. **局域网传输仍为明文。** 用户明确选择保留兼容性并提示风险;提示和确认不等于加密,不抵御同一网络的流量观察者。
3. **签名客户端需要首次迁移。** 更新来源已同步当前仓库,第三方运行包来源保持原样;从原发布方客户端迁移到本项目身份应手动安装已核验的新包。
4. **Windows 与 Android 真机验收继续暂缓。** 包含解码/渲染、轨道切换、后台音频、焦点、屏幕旋转和真实服务器边界。Linux 系统依赖库版本也不等同 Windows 固定库。
5. **GitHub Actions 已实际验证,正式发行未执行。** 当前仅配置更新签名 Secret,Android 既有签名及功能编译凭据尚缺。具体结果见下面云端验证记录。
6. **许可说明不等于全部发行合规已验完。** 未重发旧补帧包,未核验所有模型和运行库的具体再分发条件及整包源码对应关系。

搜索已使用透明结果上限,继续无限分页不是本次报告要求的唯一方案。首页布局、默认采集指标和超大播放页面重构属于产品或长期演进建议,本轮不扩大到这些改动。

## 本地交付

Windows 候选包为 `build/pack/LinPlayer-Windows-v2.0.0-dev.zip`（约 107.5 MiB）,以仓库 VERSION 加开发后缀生成,包含真实 Windows x64 外壳、交叉构建核心库和固定版本 libmpv。三份 PE 的 x64 标识、ZIP 完整性和必备文件均已检查,没有用户数据目录。签名修正后已刷新核心库和候选包,确认公钥存在、私钥未进入三份原生 PE,并生成及验证包外的 `SHA256SUMS.txt.sig`。它是开发候选,未包含云端编译凭据,未在 Windows 执行;不等同原 Windows 打包脚本的真机版本回读与正式发行验收。构建产物留在忽略目录,不入库。

后续步骤按顺序为:验证真实发布环境并补齐必要凭据 → 完成独立存储密钥备份 → 恢复各端设备验收 → 再讨论发布。F10/F13 的功能修正和本地验证已落地,上述外部配置及设备边界仍需保留。
