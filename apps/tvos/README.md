# tvOS 客户端（开发中）

正式源码使用 SwiftUI 浏览/导航、UIKit 视频表面和 AetherEngine 7.39.0 默认 traits。登录、账号、媒体资料、播放地址、续播与上报仍经 Go C ABI；不是前置播放探针的改名。

早期最小版正式 Release 已签名、安装并由用户确认能够启动。本次产品对齐源码已补齐主要原生浏览、管理与播放入口；最新327条绑定对应源码已通过正式Swift检查、开发签名Release构建、静态符号、九个动态框架闭包及声明资源检查，并更新安装到tvOS27真机。实际截图确认启动和新进程免登，真实首页资料与图片已加载。完整Keychain恢复、遥控焦点、真实播放与服务端进度读回仍有未验条目。设计正本见 [UI_TVOS](../../docs/go-migration/UI_TVOS.md)。

## 工具与固定输入

需要能编译 Swift tools 6.1 的 Xcode、tvOS SDK、Python 3.9+ 和 Go 1.27。当前检查主机是 Xcode 27.1 / SDK 27 / Go 1.27.2；deployment target 为 tvOS 18，未在 18 设备验证。只准备 arm64 真机切片，不要求下载模拟器。

```sh
python3 scripts/fetch-tvos.py
python3 scripts/fetch-tvos.py --verify
bash scripts/build-core-tvos.sh
bash scripts/check-tvos-ui.sh
```

前两条可在非 Apple 主机准备输入，后两条在 Mac 执行。`build-core-tvos.sh` 只构建 Go 静态库和真实 C 头文件；`check-tvos-ui.sh` 只编译依赖模块、类型检查正式源码及运行测试可执行文件，都不生成 .app。`check-tvos.sh` 可单独运行不依赖媒体/签名的 Swift 绑定与参数回归。

`dependencies.lock.json` 固定七个源码版本/树摘要、MPVKit 1.1.0-n9.0.2 的 28 个归档来源/上游 checksum 及真机切片摘要。源码树摘要基于已核查输入在本地计算，不是上游独立签发的校验值。`fetch-tvos.py` 可显式指定离线源码/原生归档，仍按同一锁校验；当前已验证离线输入路径，首次全网络获取尚未验证。

固定源码先校验，再将包引用改为本地路径（网络获取时）、移除失效远端 pins、禁用 Aether 中央日志出口。源码与原生库的缓存摘要在每次检查前复验，SwiftPM scratch/cache 独立放在 `.toolchain/`。不直接修改缓存中的依赖来修产品。

## 安全存储与网络

`-tags tvos` 在命令注册前安装 Keychain 后端；`config.json`（账号/设备标识）和 `blocklist.json` 由 Go 序列化并直接写入 Keychain，不先写 Caches 再复制。安全读取仅将 `errSecItemNotFound` 当缺失；损坏、权限/存取失败会阻止浏览。其它平台保持文件后端。沙盒 Caches 只承担可重建内容及不承诺跨清理保留的历史。

早期裸模拟器进程的 Security 编译检查通过，但运行被应用签名/权限策略拒绝。现已补应用内集成检查，在已启动的 arm64 tvOS 模拟器上运行 `bash scripts/check-tvos-keychain.sh <模拟器UUID>`。此可选检查需要模拟器运行时；每轮生成独立应用身份、Keychain访问组和合成条目，直接调用生产C辅助函数，自动清条目并卸载临时宿主。调用者负责关闭自己启动的模拟器。

当前工具链已通过写入/覆盖、终止进程并清除测试宿主缓存后读取、删除后新进程确认缺失；删除条目的故障注入能使读取阶段失败。模拟器权限通过链接器嵌入 `__TEXT,__entitlements`，不复用真机签名参数。该检查未接Go初始化和正式账号，不能替代正式签名应用的Keychain验收，不能据此声称已验证清缓存免登。

正式应用已取得更新后、重启后及正式设置清缓存后新进程免登的真机截图：清理页显示Zero KB和「已完成」，重启直接显示真实首页资料与图片。首次登录、设备标识连续性、损坏/写入失败及退出不复活仍须分别验证。真机清缓存使用「设置→存储与数据目录→清理缓存」；开发者文件传输的remove-existing-content曾报错并造成原数据根暂时无法列举，本机历史影响仍未确认，不用它替代正式清理入口。

服务器由用户运行时输入，支持固定 IP 的 HTTP 媒体与字幕，因此 Info.plist 明确允许任意 HTTP 载入并请求本地网络权限。这个 ATS 例外覆盖本应用 URLSession，范围不局限于局域网；HTTPS 仍使用默认信任校验。正式应用已显示真实首页资料和图片，首次本地网络授权弹窗尚未实测。图片使用核心回环通道和 `X-LP-Token` 请求头；身份变化取消请求并清缓存。媒体/字幕只读取核心返回资源，不向跨源地址追加主服 token。

## 显式出包

仅在用户直接要求出包后，在实际构建连接中提供 `LP_APPLE_TEAM` 与 `LP_APPLE_SIGN_IDENTITY`，执行 `bash scripts/pack-tvos.sh`。脚本先实际调用私钥签临时可执行文件，再构建、严格验签、查最终静态符号和九个动态框架闭包，归档到 `build/tvos/LinPlayer-tvOS-v${VERSION}.app`，不会安装。版本来自根 VERSION；真实身份不写入工程。

早期最小版已完成签名、严格验签和更新安装；本次对齐版在用户解锁后也已通过签名打包、严格验签和更新安装；签名团队取自有效描述文件的 TeamIdentifier，不从证书显示名推断。此前无签名 Release 的最终链接与静态符号检查已通过，不能据此宣称新版签名或真机验收通过。准备脚本保留源码包的 LICENSE / NOTICE / FFmpegBuild LICENSES，并作为 Notices 资源接入工程，包含日志修改说明及固定来源；MPVKit 静态闭包的完整发行许可、重链接材料仍待分发前核查。此开发入口不代表可发行包已完成。

## 真机验收顺序

1. 已签名正式应用先验证 Keychain 新装、跨进程、清缓存恢复、保存失败及退出不复活；失败先修存储。
2. 遥控器验证登录、库分页、电影/剧集、切季、返回焦点和面板逐层退出。
3. 验证 SDR 画面/声音、暂停/定位、实际双音轨切换、文本字幕选择/关闭及挂起无自动声音。
4. 显式停止后从服务器独立读回位置，再用全新进程续播；断网/失效凭据分别验反馈。

ASS/PGS 等复杂字幕明确提示不支持；HDR/DV、对象音频、最低系统及长期稳定性未验。源码已接入同季选集、上下集、5 秒自动下一集及本机开关，尚待真机验收。插件原生宿主、手机伴侣、网页/文件承接仍未完成；TV 隐藏下载，后台播放、PiP 和商店发布不在本次范围。

## 模拟器布局检查

在已启动的tvOS模拟器上运行 `bash scripts/check-tvos-visual.sh <模拟器UUID>`，截图输出到 `build/tvos-visual/`。宿主加载正式浏览、设置与PlayerView，使用合成命令/封面/视频表面；目前已运行的版本覆盖23个页面状态及3张下半页截图；本批新增加载样式预览/资源断言，尚待重跑。脚本检测夹具断言、截图失败和进程提前退出，结束自动终止并卸载测试宿主；调用者负责关闭自己启动的模拟器。

此入口会生成临时测试.app，不生成正式客户端交付包。脚本通过不等于自动视觉比对通过，需要人工查看截图；不覆盖真实Aether解码、遥控滚动、输入键盘和最低系统兼容。正式类型检查另运行check-tvos-ui.sh。
